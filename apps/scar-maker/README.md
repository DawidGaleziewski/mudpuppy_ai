# Scar maker

Real obstacles from customer sites, one per page, so the harness can be hardened against them
locally (roadmap `[battle-tested-scar]`, spec 030). Start: `pnpm --dir apps/scar-maker start`, then
open http://127.0.0.1:4300/. The catalogue of scars is `scars.yaml`; agent notes in `CLAUDE.md`.
