# A2UI catalog for the Workbench (R-96 spike)

Generated by `../tools/gen_wb_schema.py` from the same catalogue as `../schema/view-spec.schema.json`. Do not edit the JSON by
hand. The design and the binding rules: `docs/19-console-answers/13-a2ui-catalogue.md`.

| File | What |
|---|---|
| `catalog.json` | The catalog (A2UI v0.9.1 shape): 15 agent components + View and CommandCard (server-owned) |
| `examples/*.jsonl` | Server → client message streams compiled from the view-spec examples (`*.client.jsonl`: client → server actions) |
| `examples/refused.json` | Messages from an agent that speaks A2UI itself which the server drops, with their codes |
| `check.py` | Validates the streams against the catalog; the reference filter for agent messages. `python3 check.py` |

Rules in one line each: the agent sets ids and options; the server adds `data` paths and writes the data model; View and
CommandCard are the server's; `root` is View's id; writes go through CommandCard and `command.confirm`.
