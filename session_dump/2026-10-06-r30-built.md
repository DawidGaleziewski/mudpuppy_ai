## Traps learned this session

- The commit hook is a `PreToolUse` hook: it runs before the whole Bash command. Dashboard
  changes need the chat service up for the smoke test (F-23): start it in an earlier command.
- Stop services by the process group recorded at start (`ss -ltnp` → pid → pgid), never by a
  `grep` match (the dashboard was killed by mistake once).
- `setsid cmd &` forks; the `$!` pid is not the service.
- The dashboard does not reload code: restart it after Python/template changes before a
  screenshot. Playwright for screenshots: run scripts from `apps/crawler/packages/crawler`.
