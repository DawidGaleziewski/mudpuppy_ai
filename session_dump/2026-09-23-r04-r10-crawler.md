## Decisions made (not all in the original spec)
- The server records into `data/db/<PATHFINDER_ENV>.sqlite` (default `production`); portals of another environment
  are refused with `ENV_GUARD_REFUSED`.
- New contract items: portal `block_signatures`; error codes `SAFETY_CLASS_MISMATCH` and `UNKNOWN_REF` (also for
  `add_open_question`); action `nth` and `snapshot_ref`.
- Frontier is one table: `pending`, `done`, plus five skip statuses. Decision log is a table, mirrored by pino.
  Timestamps are ISO text with ms, ids UUIDv7, `runs.mode` has no CHECK.
- `act` on an action from another state re-navigates to its `page_url` through the same gates.
- Budget exhaustion completes the run then returns `RUN_STOPPED`; stale `running` runs become `interrupted` on
  server boot and shutdown (`interruptStaleRuns`).
- Fingerprint index is rebuilt at session open from stored masked snapshots, in creation order.
- pnpm: `esbuild: false` in `pnpm-workspace.yaml` (denied, tsx works); root depends on `@pathfinder/core` for scripts.
