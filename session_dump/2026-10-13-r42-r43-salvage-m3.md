## Lessons (keep applying)

- Stage in a separate Bash call from `git commit` (F-07). `git merge -F -` does not read stdin:
  write the message to a file.
- Never `pkill -f` (kills the own shell); stop servers by PID.
- `tojson` in an attribute → single quotes (F-11); check rendered attributes, not just the server.
- Run the export dry run before every interim merge (it caught F-07 and F-12).
