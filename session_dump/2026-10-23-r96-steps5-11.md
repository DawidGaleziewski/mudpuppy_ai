## Patterns to reuse

- Router logic the API needs lives in non-router modules (G-13): `queries_app_*`, `views_*`,
  `web/chat_writes.py`, `web/api_common.py`, `suite_form.py`, `settings_forms.py`.
- Writes: `chat_writes` (`WriteResult`, `write_answer`, `write_refused`, `chat_write`); React
  `useConfirmedWrite` (`Ask` with `follow`, `onDone`, `undo`). Statuses only from the API.
- Long content per kind → API blocks (`queries_app_doc_content.py`); filters apply on a button;
  ≤5 params (query models); no `# fmt: skip` inside expressions; no lint suppressions.
- Visual checks without data: scratch stores from test fixtures (`tests.conftest.make_store` +
  seeds); the drawer: scratch Playwright script setting `mudpuppy.assistant.open` in
  sessionStorage. After a real chat-service run, stop its PID chain; leave this session's
  `mcp-server` processes alone.
- Edits only with the Edit tool (a hook blocks heredoc writes to tracked files).
