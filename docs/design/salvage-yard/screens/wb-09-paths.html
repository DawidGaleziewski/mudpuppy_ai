One tab, four paths

The assistant picks a path from what you ask; the path decides which components it composes and where they sit. You can always switch it. Areas marked “generated” are composed by the assistant from the catalogue; their frames are solid because what they show is observed. The rest is fixed.

Path rules

  1. 1 · The assistant proposes the path and says why, next to the Path switch ("you asked to map").Proposed
  2. 2 · You can switch at any time; your switch wins until you ask for something new.You decide
  3. 3 · Changing path never clears the conversation; the stage swaps, the stream stays.Kept
  4. 4 · The path is in the URL (?path=mapping&scan=01a110d5-2028-7000-8f3e-5c1a9b27d460), so a view can be linked and reloaded.Linkable
  5. 5 · A stage that changes announces it once ("Live map opened") and never steals focus.Calm
  6. 6 · If the assistant can't build a view, it answers in plain chat. Nothing breaks.Fallback
  7. 7 · The assistant picks what to show; the server decides where (placement comes from the path and the phase).Placement

Point and ask

Everything on the stage can become context: click a page and "Ask about this", type @ to point at a page, step or event, or press A on a focused item. Asking about@/kontakt · step 171 The chip travels with the message as structured context (page id, step, scan), not as pasted text.
