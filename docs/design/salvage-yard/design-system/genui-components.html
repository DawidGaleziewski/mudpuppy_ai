Salvage Yard · gen UI components

The parts the Workbench needs because the assistant composes the screen. Load genui.css after salvage.css. Two kinds: frame components (the server always owns them: layouts, the generated frame, Why, feedback, narration, context, commands) and catalogue components (the only things the assistant may place, listed at the end and defined in workbench/schema/). Rules: docs/15-genui-guidelines.md · reference: docs/16-genui-components.md · screens: screens/wb-01…wb-10.

What the paint means in a generated view

The arrangement is generated; the facts are not. So the frame is solid and carries a small mark, and only the assistant's own words are dashed.

generatedThe view was chosen by the assistant. Its frame stays solid because the data in it is observed.
  1. 10:51:02ZFollowed 'Samochód'.step 38
Dashed blueprint = written or chosen by the assistant: narration, Why, suggestions, a drafted command.
Crawler hereCyan = happening now: the crawler's position, a running command, the live stream.
Marker = the one decision on screen. Send is never marker in the Workbench.
Failed hereRed = something failed in the scan or the portal. A view that couldn't be built is not red.
Not liveGrey dashed frame = stale: the stream dropped; the data is still readable.
